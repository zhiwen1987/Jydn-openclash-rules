# Jydn OpenClash Public Rules

This repository contains only the public OpenClash conversion template and domain/IP rule payloads exported from the private project. It contains no subscriptions, proxy nodes, credentials, internal operational records, or production databases. The public `webrtc-client.yaml` is deliberately an empty placeholder; each deployment injects its site-specific LAN rule from a local authenticated file provider.

Files are generated by an allowlist publisher. Direct edits may be replaced by the next verified publication.
